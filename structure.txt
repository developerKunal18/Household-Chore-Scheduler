Features
- Add, view, edit, and delete household tasks.
- Assign tasks to family members.
- Set task priorities: Low, Medium, and High.
- Set due dates and track overdue tasks.
- Mark tasks as completed.
- Filter tasks by person, priority, and status.
- Generate a task summary report.
- Save data automatically in a JSON file.
